# 💬 React Native Chat App

A real-time chat application built using React Native and Firebase.

---

## 🚀 Features

* User Authentication (Login / Register)
* Real-time messaging
* Chat rooms
* Redux state management
* Clean UI

---

## 🛠 Tech Stack

* React Native (Expo)
* Firebase Authentication
* Firebase Realtime Database
* Redux Toolkit
* React Navigation

---

## ⚙️ Setup

git clone https://github.com/uday134/rn-chat-app-uday.git
cd rn-chat-app-uday
npm install
npx expo start
